This calculator converts yarn dimensions using the classic textile formulas:

System Type Formula Standard Unit
Tex Direct (g ÷ L) × 1000 g per 1,000 meters
English (Ne) Indirect 590.5 ÷ Tex 840-yd hanks per lb
Denier (D) Direct 5315 ÷ eng g per 9,000 meters
Metric (Nm) Indirect eng ÷ 0.59 Meters per 1 gram
Direct Systems (Tex, Denier): Fixed length, variable mass. The heavier/thicker the yarn, the higher the number.
Indirect Systems (English Ne, Metric Nm): Fixed mass, variable length. The finer/thinner the yarn, the higher the number.
